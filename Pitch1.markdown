- **Notes**:
  - Emphasize the scale: “Fraudsters are smarter than ever, exploiting digital transactions.”

    - API (FastAPI) for integration with banking systems.
    - Two modes: Machine Learning (ML) models (XGBoost, Random Forest) and rule-based analysis.
    - Features: Synthetic data generation, model training, visualizations, real-time predictions.
  - Visual: Screenshot of Streamlit app or API workflow diagram.
- **Notes**:
  - Highlight ease of use: “Banks can integrate our API in minutes.”
  - Mention accuracy: “Our ML models catch anomalies with high precision.”
