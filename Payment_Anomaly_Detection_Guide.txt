# Payment Anomaly Detection Project Guide for Python Beginners

## Abstract
This guide introduces Python beginners to a Payment Anomaly Detection web application built with Streamlit. The project detects suspicious financial transactions using machine learning (ML) or rule-based methods. It covers data generation, preprocessing, model training, evaluation, real-time predictions, and visualizations. The guide explains each file, provides code snippets, and includes a workflow diagram to illustrate the project's flow.

## 1. Project Overview
This web application detects anomalous financial transactions, such as fraud, using two approaches:
- **ML-Based**: Uses machine learning models (Random Forest, Logistic Regression, XGBoost) to predict anomalies.
- **Rule-Based**: Analyzes data with predefined rules and visualizes results with charts and maps.

**Key Features**:
- Generate synthetic data for customers and transactions.
- Preprocess data for ML.
- Train and evaluate ML models.
- Show insights (charts, feature importance).
- Real-time detection form.
- Data dictionary for understanding fields.
- Visualizations like maps and histograms.

The app uses libraries like Pandas, NumPy, Scikit-learn, XGBoost, SHAP, Matplotlib, Seaborn, and Folium.

## 2. Prerequisites
- **Python 3.8+**: Install from python.org.
- **Libraries**: Install using:

## 3. File-by-File Explanation

### 3.1 `data_generation.py`
**Purpose**: Generates synthetic customer profiles and transaction data, saved as CSV/JSON.

**Key Concepts**:
- Uses `Faker` for realistic data (e.g., names, IPs).
- Calculates "impossible travel" based on timestamps and locations.
- Saves data with Pandas' `to_csv` and JSON.

**Main Functions**:
- `generate_data(num_records=1000)`: Creates customer and transaction DataFrames.
- `save_data(...)`: Saves to CSV.
- `save_retrain_data(...)`: Saves JSON for retraining.

**Code Example**:
```python
import pandas as pd
import numpy as np
from faker import Faker
fake = Faker()
def generate_data(num_records=1000):
    customers = pd.DataFrame({
        'customer_id': [fake.uuid4() for _ in range(100)],
        'nationality': np.random.choice(['US', 'IN', 'UK'], 100)
    })
```

**Tip**: DataFrames are like Excel tables. `np.random.choice` picks random items.

## 4. How the Files Connect
`app.py` orchestrates everything:
- **Generate Data**: Calls `data_generation.py`.
- **Preprocess**: Calls `preprocessing.py`.
- **Train/Evaluate**: Calls `model_training.py`.
- **Insights**: Calls `insights.py`.
- **Real-Time**: Calls `inference.py`.
- **Rule-Based**: Calls `rule_based.py`.
- **Dictionary**: Calls `data_dictionary.py`.

Data flows: Generate → Preprocess → Train → Predict/Insights. Models/data are saved in `models/` and `data/`.

## 6. Running the Project
1. Save all `.py` files in one folder.
2. Open terminal in the folder.
3. Run: `streamlit run app.py`.
4. Browser opens the app.
5. Follow sidebar: Choose mode, set records, click buttons (Generate → Preprocess → Train → Evaluate → Insights).

## 7. Tips for Beginners
- **Debugging**: Add `print("Here")` to trace code. Check `st.error()` messages.
- **Common Issues**: Missing columns? Check data generation. Model errors? Ensure `models/` exists.
- **Resources**:
  - Streamlit: docs.streamlit.io
  - Pandas: pandas.pydata.org/docs
  - Scikit-learn: scikit-learn.org
- **Experiment**: Modify `num_records` or add fields.
